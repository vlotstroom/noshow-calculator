# No-show cost calculator

Free single-file calculator for salons, clinics and studios: what no-shows
and late cancellations cost per week, month and year, and what a reminder
flow could recover at a target rate you set yourself.

- One HTML file, no build step, no tracking, no requests: runs fully in the
  browser.
- English and Dutch interface.
- Plain math only: weekly loss = appointments x no-show rate x average
  appointment value. Month = 4.33 weeks. The tool claims no fixed
  improvement; you set the target rate.

Run it: open index.html in any browser, or use the hosted copy at
https://vlotstroom.github.io/noshow-calculator/
